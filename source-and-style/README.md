Website Selected: musicmap.info
Website URL: https://musicmap.info
Why I Chose It: I chose this website because my groups common interest is music, so I thought this could be cool to compare to our group project.

What Technologies Were Used: Based on my inspection of the website using the browser Developer Tools the meain technologies used were HTML, CSS, and JavaScript files. I found that they used YouTube.com as a .jss file, fonts.googleapis as a .css file, and musicmap.info as a .woff2 file.

Who built this website: Musicmap.info was created and built by Belgian architect Kwinten Crauwels, who spent over seven years researching and designing the interactive music genre genealogy. Github Link: https://github.com/sounak98/musicmap
I searched for "musicmap GitHub" and found the official repository

The musicmap.info website is a data visualization tool that uses:
1. Frontend Framework: [React/Vue/etc]
2. Data Visualization: [D3.js/Three.js/etc - for creating the interactive music map]
3. Styling: CSS and Bootstrap
4. Fonts: Google Fonts (loaded as .woff2 files)
